# Security policy

## Supported version

Security fixes are applied to the latest commit on `main`. Keep the locked
dependencies current when deploying this example.

## Report a vulnerability

Please do not open a public issue. Submit a private report through
[GitHub Security Advisories](https://github.com/CorsenAI/corsen-context-express/security/advisories/new)
with reproduction steps, affected routes, and the observed impact.

This example is designed for public, read-only content. Review the provider
before deployment and never expose drafts, account data, credentials, or
personalized responses through its MCP or static discovery routes.
